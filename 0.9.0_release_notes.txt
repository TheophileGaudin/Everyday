New widget

- Map widget: A minimap which shows roads around you and points of interest. Responds to head motion. 3 levels of zoom, toggled between projected and top down view. Intentions in the future: make it a proper directions map.

Extension:

- Image widget is now a more general file explorer, enabling to read pdf or run video files.

Optimizations

- The Standard layout now includes the minimap widget
- One widget is active at a time and its buttons can be hit, rather than widgets under it.
- Only the widget container now owns the black background
- Widgets can be dimensioned very small if needed

Bug fixes

- Fixed candles not appearing when selected for currencies (fx)
